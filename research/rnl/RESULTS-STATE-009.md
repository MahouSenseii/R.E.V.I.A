## What the comparisons establish

Under the same selected-reader family, initialization policy, data and budget,
trained states supported 67/77/61 more correct individual answers than initial
states: a pooled 10.17 percentage-point margin. Both readers were trained; only
their encoder states came from initial versus trained weights. This is a
descriptive paired feature-condition contrast under new probe supervision, not
a direct test of the original network's QUERY transition or a hidden algorithm.

Selected trained readers answered both queries correctly on 12/15/12 pairs by seed,
39/1,008 pooled, compared with 7/8/9=24/1,008 for initial-state readers. The deeper
saved-row audit found 15 trained-feature three-of-four group-runs (3/5/7 by seed)
versus 3 initial-feature group-runs (0/2/1), and zero for blind. These useful partial
responses remain below the unchanged four-of-four screens; they are not new gates
or 15 independent/unique groups.

Selected versus blind individual accuracy differs by 3 fewer/2 more/4 fewer answers
by seed: selected 550 versusblind 555 overall. Both were correct 443 times, selected
alone 107, blind alone 112, neither 1,354. They produced the same class on 1,596/2,016
cases (79.17%). Delay-specific differences were mixed.

Near-equal aggregate accuracy does not prove equivalence or that the query is
unused. These are separately trained readout policies: averaging four heads
collapses to one affine map, while supplied-key selection has a different
effective function family and gradients. Nominal parameter equality does not
make that comparison a pure causal intervention on query information.

A closer within-reader posthoc check uses already saved outputs for the other
queried key on the identical history, scoring the original question's target.
Correct-query versus corrupted-query scores
were 187/189,186/173,177/171 for trained selected: 550 versus 533 overall, a net 17 answers
(0.84 percentage points), with mixed seed signs. Initial selected was 345 versus 350;
blind 555 versus 555. This swaps only the two recorded queried keys, not arbitrary
keys, and adds no model call or success criterion. There were 171 original-only
successes and 154 corrupted-query-only successes, which cancel in the net margin.
It measures this fixed
reader's output response; it does not identify what facts its state encodes.

Conditional on choosing either candidate answer, the requested answer accounted
for 50.78%/50.00%/49.64%. These proportions do not prove both facts were retained
or that a model guessed between them. The global last-write rule cannot explain
correct answers here; that does not rule out all recency or value-history cues.

Switching only the query left the class unchanged in 688/1,008 trained-selected
pairs (68.25%), 1,008/1,008 blindpairs and 313/1,008 initial-selected pairs (31.05%).
Exchanging the earlier target values left classes unchanged in 802/1,008,
766/1,008 and 827/1,008 pairs respectively. Class sensitivity alone is not accuracy;
query-only variants share identical cached pre-query states by construction,
while an identical predicted class can conceal changed reader logits. Earlier-
value swaps can also change the encoded history state; equal classes do not
establish state equality there. Logits were not retained. This is not a controlled comparison with STATE-008's
different evaluation histories and decoder treatment.

Diagnostic mean accuracy at 0/168/1008 reader updates was 13.29/22.82/27.53% for
trained selected, 13.49/24.40/26.93% for blind, and 12.85/14.09/18.01% for initial
selected. Three points do not establish convergence. All 27 curve records, exact
per-seed/delay counts and posthoc contrasts remain in the public aggregate.

## Next question and alternative leads

Recommended single question: can a small nonlinear reader improve complete
keyed recall from the same saved trained states, beyond both a matched identity
reader and the direct linear reference? A shared 32-to-16 projection plus four
16-to-8 heads has 1,072 parameters; compare identity with ReLU using identical
initial tensors/data/order. Retain the direct 1,056-parameter reference so recovery
from factorization loss is not mistaken for addressing STATE-009's gap.
Each uses 1,024 main matrix MACs, but total computation/optimization differs.
Fresh grouped training/confirmation data, fixed margins, exact snapshot loading,
resource/output checks and independent execution approval are still needed.
No next-probe code, new dataset or training has been run.

A positive probe would support that decoder family under new supervision, not
diagnose the original failure cause. A negative cannot prove absent information,
convergence or failure of nonlinear readers generally. This interpretive limit
is consistent with the primary [review of probing classifiers](https://arxiv.org/abs/2102.12452).

Two alternatives remain separate hypotheses: a learned keyed write/read state
(or delta-rule associative update), and an end-to-end GRU training-distribution
control. [End-To-End Memory Networks](https://arxiv.org/abs/1503.08895) provides
prior art for differentiable memory retrieval; [DeltaNet section 2.2](https://arxiv.org/html/2406.06484v3)
describes a content-dependent remove/write update. These motivate architecture
leads, not a prediction of RNL performance. A later comparison must hold data,
presentations and actual parameter/state budgets explicit. Supplied exact keys/
overwrites must not be called learned routing. Changing architecture and training
distribution together would test the whole recipe rather than identify a cause.

This is one proposed bounded reader follow-up, not indefinite toy optimization.
Its outcome should inform a choice between training-recipe and explicit-state
architecture controls. The broader adaptive/stateful RNL question stays open.
No application candidate, LLM quality or cross-request memory is established.
